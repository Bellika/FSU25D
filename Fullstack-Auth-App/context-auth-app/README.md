# Context & Authentication App

En omfattande React-app som demonstrerar moderna React-koncept.

## Vad du lär dig

- ✅ **React Context API** - AuthContext & ThemeContext
- ✅ **useRef Hook** - DOM-access, timers, och mutable värden
- ✅ **.env-filer** - Miljövariabler med Vite
- ✅ **localStorage** - Persistent theme preference
- ✅ **CSS Modules** - Scoped component styles
- ✅ **CSS Custom Properties** - Modern theming med CSS-variabler
- ✅ **Dark/Light Mode** - Theme toggle med Context

## Installation

```bash
npm install
```

## Starta

```bash
npm run dev
```

## Inloggningsuppgifter

Se `.env`-filen för användarnamn och lösenord.

Standard:
- Användarnamn: `admin`
- Lösenord: `password123`

## Features

### Dashboard innehåller:
- User authentication status
- Theme toggle (dark/light mode)
- **RefDemo component** - Interaktiva useRef-exempel:
  - Focus management
  - Render counter
  - Previous value tracking
  - Scroll to element
  - Timer med setInterval
